## Authentication System

### Hub-Generated Tokens

The Hub **pre-generates** unique authentication tokens for each satellite. Satellites do NOT register themselves; they receive their token from the Hub administrator.

#### Token Format

```
LNDMRK_SAT_{SATELLITE_TYPE}_{UNIQUE_ID}_{CHECKSUM}
```

**Components:**
- `LNDMRK_SAT_` - Static prefix identifying this as a satellite token
- `{SATELLITE_TYPE}` - Type identifier (e.g., `TRAINING`, `NUTRITION`, `SCHOOL`, `PHYSIO`)
- `{UNIQUE_ID}` - 32-character alphanumeric unique identifier
- `{CHECKSUM}` - 8-character validation checksum

**Example:**
```
LNDMRK_SAT_TRAINING_a8f4c3e9b2d1f6a5c8e4b9d2f1a6c3e8_9f2d4a1c
```

#### Token Properties

- **Single-use context**: One token per satellite instance
- **No expiration**: Tokens remain valid unless revoked by Hub admin
- **Scope-limited**: Each token has specific data access permissions
- **Immutable**: Cannot be regenerated by satellite; must request new one from Hub

### Token Storage (Satellite Side)

Store the token in your satellite's environment variables:

```env
# .env file
HUB_API_URL=https://hub.lndmrk.com/api
HUB_SATELLITE_TOKEN=LNDMRK_SAT_TRAINING_a8f4c3e9b2d1f6a5c8e4b9d2f1a6c3e8_9f2d4a1c
```

**Security Requirements:**
- ✅ Store in `.env` file (never commit to git)
- ✅ Use environment variables in production
- ✅ Never expose in client-side code
- ✅ Never log the full token
- ❌ Do NOT hardcode in source files
- ❌ Do NOT store in browser localStorage

## Token Validation (Satellite Implementation)

### Step 1: Validate Token Format Locally

Before making any Hub API calls, validate your token format:

```typescript
// lib/hubTokenValidator.ts

interface TokenComponents {
  prefix: string;
  satelliteType: string;
  uniqueId: string;
  checksum: string;
}

export function parseHubToken(token: string): TokenComponents | null {
  const pattern = /^LNDMRK_SAT_([A-Z_]+)_([a-f0-9]{32})_([a-f0-9]{8})$/;
  const match = token.match(pattern);

  if (!match) {
    console.error('Invalid token format');
    return null;
  }

  return {
    prefix: 'LNDMRK_SAT',
    satelliteType: match[1],
    uniqueId: match[2],
    checksum: match[3],
  };
}

export function validateTokenFormat(token: string): boolean {
  return parseHubToken(token) !== null;
}

export function getSatelliteType(token: string): string | null {
  const parsed = parseHubToken(token);
  return parsed ? parsed.satelliteType : null;
}
```

### Step 2: Authenticate with Hub

Make an initial authentication request to verify the token with the Hub:

```typescript
// lib/hubAuth.ts

interface HubAuthResponse {
  success: boolean;
  satellite_id: string;
  satellite_type: string;
  permissions: string[];
  athlete_ids?: string[];
}

export async function authenticateWithHub(
  token: string
): Promise<HubAuthResponse> {
  const hubApiUrl = import.meta.env.VITE_HUB_API_URL;

  // Validate format first
  if (!validateTokenFormat(token)) {
    throw new Error('Invalid token format');
  }

  const response = await fetch(`${hubApiUrl}/satellite/auth`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-Satellite-Token': token,
    },
    body: JSON.stringify({
      token,
      satellite_version: '1.0.0',
      request_timestamp: new Date().toISOString(),
    }),
  });

  if (!response.ok) {
    throw new Error(`Hub authentication failed: ${response.status}`);
  }

  const data: HubAuthResponse = await response.json();

  if (!data.success) {
    throw new Error('Token rejected by Hub');
  }

  return data;
}
```

### Step 3: Store Authentication State

Create a React hook to manage Hub authentication:

```typescript
// hooks/useHubAuth.ts

import { useState, useEffect } from 'react';
import { authenticateWithHub } from '../lib/hubAuth';

interface HubAuthState {
  isAuthenticated: boolean;
  isLoading: boolean;
  error: string | null;
  satelliteId: string | null;
  satelliteType: string | null;
  permissions: string[];
}

export function useHubAuth() {
  const [state, setState] = useState<HubAuthState>({
    isAuthenticated: false,
    isLoading: true,
    error: null,
    satelliteId: null,
    satelliteType: null,
    permissions: [],
  });

  useEffect(() => {
    async function authenticate() {
      const token = import.meta.env.VITE_HUB_SATELLITE_TOKEN;

      if (!token) {
        setState(prev => ({
          ...prev,
          isLoading: false,
          error: 'No satellite token configured',
        }));
        return;
      }

      try {
        const authData = await authenticateWithHub(token);

        setState({
          isAuthenticated: true,
          isLoading: false,
          error: null,
          satelliteId: authData.satellite_id,
          satelliteType: authData.satellite_type,
          permissions: authData.permissions,
        });
      } catch (err) {
        setState(prev => ({
          ...prev,
          isLoading: false,
          error: err instanceof Error ? err.message : 'Authentication failed',
        }));
      }
    }

    authenticate();
  }, []);

  return state;
}
```

## API Endpoints

```typescript

const HUB_API_URL = import.meta.env.VITE_HUB_API_URL;
```

## Data Permissions by Satellite Type

Each satellite type has specific permissions defining what data they can READ and WRITE.

### Training Satellite (`LNDMRK_SAT_TRAINING_*`)

**READ Permissions:**
- ✅ Athlete profile (basic info)
- ✅ Athlete passport (physiology: FTP, zones, thresholds)
- ✅ Training schedule (all sessions with colors)
- ✅ Planned workouts
- ✅ Completed sessions (own satellite only)

**WRITE Permissions:**
- ✅ Create/update planned workouts
- ✅ Create/update completed sessions
- ✅ Update training schedule
- ❌ Cannot modify athlete physiology
- ❌ Cannot access nutrition data
- ❌ Cannot access anthropometry data

**Example Use Case:**
This satellite (current implementation) creates workouts, schedules them, and records completed sessions with power/HR/pace data.

---

### Nutrition Satellite (`LNDMRK_SAT_NUTRITION_*`)

**READ Permissions:**
- ✅ Athlete profile (basic info)
- ✅ Training schedule **COLORS ONLY** (difficulty visualization)
- ✅ Anthropometry data (weight, body composition)
- ✅ Energy expenditure estimates (from training load)
- ❌ Cannot see detailed workout structure
- ❌ Cannot see power/pace targets

**WRITE Permissions:**
- ✅ Create/update meal plans
- ✅ Record nutrition intake
- ✅ Update anthropometry measurements
- ❌ Cannot modify training data
- ❌ Cannot modify physiology data

**Example Use Case:**
Nutrition satellite views the training schedule as a calendar with colored blocks indicating training load. It doesn't need workout details, just the difficulty to plan nutrition accordingly.

**Implementation Example:**

### School Satellite (`LNDMRK_SAT_SCHOOL_*`)

**READ Permissions:**
- ✅ Athlete profile (full biological profile)
- ✅ Athlete passport (sport history, experience level)
- ✅ Training schedule dates (for attendance tracking)
- ❌ Cannot see workout details
- ❌ Cannot see training metrics
- ❌ Cannot access nutrition data

**WRITE Permissions:**
- ✅ Update educational content completion
- ✅ Record quiz/test results
- ✅ Add certifications
- ❌ Cannot modify training data
- ❌ Cannot modify physiology

**Example Use Case:**
School satellite focuses on the athlete's biological profile (age, gender, injury history) and educational progress. It sees training dates to track attendance but not the workout content.

---

### Physio Satellite (`LNDMRK_SAT_PHYSIO_*`)

**READ Permissions:**
- ✅ Athlete profile
- ✅ Full training history (volume and intensity)
- ✅ Training schedule (for injury prevention planning)
- ✅ Anthropometry data
- ✅ Injury history

**WRITE Permissions:**
- ✅ Record injury/recovery events
- ✅ Update injury status
- ✅ Add physio session notes
- ✅ Modify athlete availability (if injured)
- ⚠️ Can suggest physiology updates (requires coach approval)

**Example Use Case:**
Physio satellite monitors training load patterns to prevent overtraining injuries and records rehabilitation progress.

## Implementation Examples

### Example 1: Nutrition Satellite - View Training Colors

```typescript
// Nutrition satellite component
import { useState, useEffect } from 'react';
import { getTrainingColors } from '../lib/hubApi';

interface TrainingDay {
  date: string;
  difficulty_color: string;
  difficulty_level: 'easy' | 'moderate' | 'hard' | 'very_hard';
  estimated_duration: number;
  estimated_load: number;
}

export function TrainingLoadCalendar({ athleteId }: { athleteId: string }) {
  const [trainingDays, setTrainingDays] = useState<TrainingDay[]>([]);

  useEffect(() => {
    async function loadData() {
      const start = new Date();
      const end = new Date();
      end.setDate(end.getDate() + 30);

      const data = await getTrainingColors(
        athleteId,
        start.toISOString().split('T')[0],
        end.toISOString().split('T')[0]
      );

      setTrainingDays(data);
    }

    loadData();
  }, [athleteId]);

  return (
    <div className="grid grid-cols-7 gap-2">
      {trainingDays.map(day => (
        <div
          key={day.date}
          className="p-4 rounded-lg"
          style={{ backgroundColor: day.difficulty_color + '20' }}
        >
          <div className="text-sm font-medium">{day.date}</div>
          <div className="text-xs text-gray-500 mt-1">
            Load: {day.estimated_load}
          </div>
        </div>
      ))}
    </div>
  );
}
```

### Example 2: School Satellite - Biological Profile Only

```typescript
// School satellite - access biological profile
import { useState, useEffect } from 'react';
import { getAthleteProfile } from '../lib/hubApi';

interface BiologicalProfile {
  full_name: string;
  date_of_birth: string;
  gender: string;
  sport_primary: string;
  sport_secondary?: string;
  experience_years: number;
  injury_history?: string[];
}

export function AthleteBioProfile({ athleteId }: { athleteId: string }) {
  const [profile, setProfile] = useState<BiologicalProfile | null>(null);

  useEffect(() => {
    async function loadProfile() {
      const data = await getAthleteProfile(athleteId);
      setProfile(data);
    }

    loadProfile();
  }, [athleteId]);

  if (!profile) return <div>Loading...</div>;

  return (
    <div className="space-y-4">
      <h2>{profile.full_name}</h2>
      <div>
        <p>Age: {calculateAge(profile.date_of_birth)}</p>
        <p>Gender: {profile.gender}</p>
        <p>Primary Sport: {profile.sport_primary}</p>
        <p>Experience: {profile.experience_years} years</p>
      </div>
    </div>
  );
}

function calculateAge(dob: string): number {
  const birth = new Date(dob);
  const today = new Date();
  let age = today.getFullYear() - birth.getFullYear();
  const monthDiff = today.getMonth() - birth.getMonth();
  if (monthDiff < 0 || (monthDiff === 0 && today.getDate() < birth.getDate())) {
    age--;
  }
  return age;
}
```

## Error Handling

### Standard Error Responses

The Hub API returns standardized error responses:

```typescript
interface HubErrorResponse {
  success: false;
  error: {
    code: string;
    message: string;
    details?: any;
  };
}
```

### Common Error Codes

| Code | Meaning | Action |
|------|---------|--------|
| `INVALID_TOKEN` | Token format invalid or missing | Check token format and configuration |
| `TOKEN_REVOKED` | Token has been revoked | Request new token from Hub admin |
| `INSUFFICIENT_PERMISSIONS` | Satellite lacks permission for this data | Check satellite type permissions |
| `ATHLETE_NOT_FOUND` | Athlete ID doesn't exist | Verify athlete ID |
| `RATE_LIMIT_EXCEEDED` | Too many requests | Implement exponential backoff |
| `HUB_UNAVAILABLE` | Hub is down or unreachable | Show offline mode to user |

### Error Handling Implementation

```typescript
// lib/hubApiClient.ts

export class HubApiError extends Error {
  constructor(
    public code: string,
    message: string,
    public details?: any
  ) {
    super(message);
    this.name = 'HubApiError';
  }
}

export async function handleHubResponse<T>(response: Response): Promise<T> {
  if (!response.ok) {
    const errorData = await response.json().catch(() => null);

    if (errorData?.error) {
      throw new HubApiError(
        errorData.error.code,
        errorData.error.message,
        errorData.error.details
      );
    }

    throw new HubApiError(
      'UNKNOWN_ERROR',
      `HTTP ${response.status}: ${response.statusText}`
    );
  }

  return response.json();
}

// Usage
try {
  const data = await handleHubResponse(response);
  // process data
} catch (err) {
  if (err instanceof HubApiError) {
    switch (err.code) {
      case 'INVALID_TOKEN':
        // Show token configuration error
        break;
      case 'INSUFFICIENT_PERMISSIONS':
        // Hide UI elements this satellite can't access
        break;
      case 'RATE_LIMIT_EXCEEDED':
        // Implement retry with backoff
        break;
      default:
        console.error('Hub API error:', err.message);
    }
  }
}
```

## Rate Limiting

The Hub implements rate limiting per satellite:

- **Standard tier**: 100 requests per minute
- **Burst tier**: 500 requests per 5 minutes
- **Daily limit**: 50,000 requests per day

### Implementing Rate Limit Handling

```typescript
// lib/hubRateLimiter.ts

class RateLimiter {
  private queue: Array<() => Promise<any>> = [];
  private processing = false;
  private lastRequest = 0;
  private minInterval = 600; // 100 req/min = 600ms between requests

  async execute<T>(fn: () => Promise<T>): Promise<T> {
    return new Promise((resolve, reject) => {
      this.queue.push(async () => {
        try {
          const result = await fn();
          resolve(result);
        } catch (err) {
          reject(err);
        }
      });

      this.processQueue();
    });
  }

  private async processQueue() {
    if (this.processing || this.queue.length === 0) return;

    this.processing = true;

    while (this.queue.length > 0) {
      const now = Date.now();
      const timeSinceLastRequest = now - this.lastRequest;

      if (timeSinceLastRequest < this.minInterval) {
        await new Promise(resolve =>
          setTimeout(resolve, this.minInterval - timeSinceLastRequest)
        );
      }

      const fn = this.queue.shift();
      if (fn) {
        this.lastRequest = Date.now();
        await fn();
      }
    }

    this.processing = false;
  }
}

export const hubRateLimiter = new RateLimiter();

// Usage
const data = await hubRateLimiter.execute(() =>
  fetch(`${HUB_API_URL}/athletes/${athleteId}/profile`, {
    headers: getHeaders(),
  }).then(r => r.json())
);
```
